# xauatusa.org

西安建筑科技大学美国校友会官网 · XAUAT U.S. Alumni Association website.

- 视觉：会徽方案 B（金棕色圆徽 · 五角星 + 校门），配色与字体按《VI 视觉识别系统 20261009》。
- 技术：React + Vite + Tailwind，静态站点，托管在 GitHub Pages，域名 xauatusa.org（Namecheap）。
- 改文字：编辑 `src/content.ts`（中英文都在这里），然后 `pnpm install && pnpm vite build`，把 `dist/` 推到 `gh-pages` 分支。
